# 足利ごみ分別AI（非公式）

写真または品目名から、足利市の家庭ごみの分別・出し方を確認する、個人開発の静的Webアプリです。

> 本プロジェクトは個人が自主的に開発した非公式プロジェクトです。足利市が開発、提供、監修又は保証するものではありません。AIによる画像判定は参考情報です。最終的な分別・排出方法は、必ず足利市公式情報で確認してください。

## 現在の完成状態

| 段階 | 開き方 | 状態 |
|---|---|---|
| STEP1 AIなし試作版 | `step1.html` | 完成。画像プレビュー、50品目検索、追加質問、分別表示が動作します。 |
| STEP2 画像AI搭載版 | `step2.html` | 組込み部分は完成。学習画像が未提供のため、モデルは未作成です。安全に手動検索へ切り替わります。 |
| STEP3 一般公開版 | `index.html` | GitHub Pagesへそのまま公開できる構成です。AIモデル未作成時も利用できます。 |

現在、画像AIが実際に判定できる品目は **0品目** です。写真提供後に8品目＋「その他・不明」の初期モデルを学習・評価し、合格したモデルだけを組み込みます。見かけだけの判定や架空の精度は表示しません。

## できること

- スマートフォン・PCで画像を選び、その場でプレビュー
- 漢字・ひらがな・カタカナ・同義語・部分一致による品目検索
- 50件の代表品目から、分別区分、出し方、注意、公式根拠を表示
- 大きさ、電池、中身、破損、居住地区などの追加質問
- 名草地区のプラスチック類実証分別に対応
- AIモデル未作成・読込み失敗・低確信度時の手動検索
- AI搭載後は上位3候補・確信度・「はい／違います」を表示

## 画像とプライバシー

選択画像は、`URL.createObjectURL()`で端末内のブラウザに表示します。画像をサーバーへ送信する `FormData`、`XMLHttpRequest`、`sendBeacon` 等は実装していません。AI搭載後もモデルをブラウザへ読み込み、端末内で推論する設計です。

次の機能もありません。

- ユーザー登録・ログイン
- 画像保存・サーバー送信
- 位置情報取得
- Cookieを使う追跡
- アクセス解析・広告
- APIキー・外部生成AI API

## PCで確認する方法

`data/garbage_rules.json` を読み込むため、`index.html`のダブルクリックではなく、次のいずれかを使います。

- いちばん簡単：GitHubへ全ファイルをアップロードし、GitHub Pagesで確認
- PythonがあるPC：このフォルダで `python -m http.server 8080` を実行し、Edgeで `http://localhost:8080/` を開く

Pythonやコマンド操作が不安な場合は、ローカル確認を省き、GitHub Pagesで確認して構いません。詳しくは `docs/04_GitHub_Pages公開手順.md` を参照してください。

## AIモデルを追加するとき

ユーザー本人がPythonや学習設定を操作する必要はありません。

1. `docs/02_第1回AI学習用写真撮影指示書.md` に沿って撮影
2. 品目別にまとめてWorkへ提供
3. Workが整理、重複確認、学習・検証・誤判定分析を実施
4. 未使用テスト画像で評価
5. 合格後、`model/`へモデルを配置し `manifest.json` を更新

## 分別データを変更するとき

`data/garbage_rules.json` だけを編集します。AIモデルは変更不要です。更新前に足利市公式情報を確認し、`official_url` と `checked_date` も更新してください。

## テスト

公開や利用にNode.jsは不要です。開発時だけ、Node.js 18以上がある場合は次を実行できます。

```text
npm test
npm run check
```

外部パッケージのインストールは不要です。現在の結果は `docs/08_テスト結果一覧.md` に記録しています。

## 重要な限界

- 初期データは代表50品目で、足利市公式の全品目を収録したものではありません。
- 事業所ごみには使えません。
- 収集日は町内ごとに異なり、本アプリでは案内しません。
- 足利市のルール変更は自動反映されません。
- 危険物・電池・ガス容器は画像だけで判断しません。
